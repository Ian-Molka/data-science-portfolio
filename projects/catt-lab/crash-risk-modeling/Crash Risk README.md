# Crash Risk Prediction and Safety Analytics

## Overview

This project focuses on identifying high-risk roadway segments through predictive analytics, statistical modeling, and transportation safety data.

The goal was to develop a scalable framework capable of detecting crash patterns and highlighting locations with elevated safety risk.

## Problem Statement

Transportation agencies require data-driven methods to prioritize roadway improvements and allocate safety resources effectively.

This project leverages large-scale crash datasets to identify risk factors associated with increased crash frequency and severity.
