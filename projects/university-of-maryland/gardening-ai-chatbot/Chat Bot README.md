# Gardening AI Chatbot

## Overview

The Gardening AI Chatbot is an AI-powered assistant designed to provide beginner gardeners with personalized plant care recommendations, troubleshooting guidance, and gardening best practices.

The project leverages Retrieval-Augmented Generation (RAG) and Large Language Models (LLMs) to combine external gardening knowledge with generative AI, improving the relevance and accuracy of responses.

## Business Problem

Many gardening resources are scattered across websites, forums, and manuals, making it difficult for beginners to find reliable and actionable information.

This project was designed to create an intelligent assistant capable of answering gardening questions in a conversational format while incorporating domain-specific knowledge.

## Objectives

- Provide personalized gardening recommendations
- Improve response quality using external knowledge sources
- Demonstrate practical applications of Retrieval-Augmented Generation (RAG)
- Explore modern Generative AI development workflows

## Methodology

### Data Collection

- Gathered gardening reference materials and plant-care information
- Processed text-based gardening resources
- Organized information into a searchable knowledge base

### Data Preparation

- Text cleaning and preprocessing
- Document chunking
- Knowledge base creation

### Retrieval-Augmented Generation (RAG)

- User questions are converted into embeddings
- Relevant gardening information is retrieved from the knowledge base
- Retrieved context is supplied to the language model
- The model generates a context-aware response

### Response Optimization

- Prompt engineering
- Context management
- Iterative testing and refinement
